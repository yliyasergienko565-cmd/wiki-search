# sheets-search

Отвечает на вопрос по таблицам менеджеров. Не «вроде у кого-то было», а
**«вот эта строка вот этой таблицы»** — со ссылкой и номером строки.

Идея: не открывать все 10 таблиц. Есть карта `sheets-index.md` (по карточке на
таблицу: менеджер, колонки, стадии, список компаний). Читаем карту → выбираем
2-3 таблицы → открываем только их → отвечаем строго по строкам.

Каталог проекта (там `sheets-index.md`, `fetch_sheets.py`, `build_sheets_index.py`,
`sheets-sources.txt`):
```
C:/Users/yliya/OneDrive/Документы/ailearning/wiki-search
```

## Что делать

1. **Проверить свежесть карты и при необходимости пересобрать.**
   ```
   cd "C:/Users/yliya/OneDrive/Документы/ailearning/wiki-search"
   python build_sheets_index.py check
   ```
   Скрипт сам решает, устарел ли индекс (нет файла; индексу > 14 дней; изменился
   список таблиц в `sheets-sources.txt`; у таблицы изменился набор вкладок).
   По выводу:
   - `OK` → идти к пункту 2;
   - `WARN` → сеть не дала проверить структуру, но индекс не стар — идти к
     пункту 2, работать по текущему;
   - `REBUILD` → **сразу пересобрать** (движок `/index-sheets`):
     ```
     python build_sheets_index.py
     ```
     дождаться `Записано: …\sheets-index.md`, затем к пункту 2. Если пересборка
     упала из-за сети, а `sheets-index.md` есть — предупредить и продолжить по
     нему; если файла нет и собрать не удалось — сказать пользователю и стоп.

2. **Прочитать карту и выбрать таблицы.** Открыть `sheets-index.md` обычным
   чтением файла. По полям `Менеджер` / `О чём` / `Колонки` / `Компании/лиды`
   выбрать таблицы, где может быть ответ:
   - вопрос про конкретного менеджера → его личная таблица (+ «общий пайплайн»,
     если нужен свод);
   - вопрос про конкретную компанию → все таблицы, где она есть в
     `Компании/лиды` (её может вести не один менеджер — это и есть ответ);
   - вопрос по срезу (стадия «демо», прогноз, источник лида) → все таблицы, у
     которых в `Колонки`/`О чём` есть подходящая колонка. Тут можно взять и
     больше 3 таблиц — брать все релевантные.
   Если ни одна карточка даже близко не подходит — пункт 5.

3. **Открыть только выбранные таблицы:**
   ```
   python fetch_sheets.py <N1> <N2> ...            # номера таблиц из карты
   python fetch_sheets.py <N> --filter Северсталь  # только строки с подстрокой
   ```
   `<N>` — номер из заголовка карточки («## Таблица 7 …» → `7`); можно передать и
   ссылку/`id`. Скрипт печатает по каждой строке `значения` и готовую строку
   `источник: …/edit?gid={GID}&range=A{N}:Z{N}`. Флаг `--json` — машиночитаемо.

4. **Ответить строго по открытым строкам.** Обязательно:
   - только то, что реально есть в строках;
   - **каждый факт — со ссылкой-источником** из вывода (`…?gid=…&range=A{N}:Z{N}`);
     несколько строк — сослаться на каждую;
   - если одна и та же компания встречается у нескольких менеджеров с разными
     стадиями — показать это и, если в примечаниях есть указание («артём ведёт»,
     «передал петрову»), опереться на него;
   - разные форматы таблиц — нормальны (у каждой свои колонки); сопоставлять по
     смыслу.

5. **Если ответа в таблицах нет.** Прямо сказать. Ничего не выдумывать.

6. **Никаких размытых формулировок** — только конкретная строка со ссылкой.

## Заметки

- Зависимостей нет — только стандартная библиотека Python 3.
- Доступ к таблицам «по ссылке», без OAuth (CSV-экспорт).
- Карту `sheets-index.md` строит `/index-sheets`. `/sheets-search` перед
  поиском сам делает `build_sheets_index.py check` и при необходимости
  пересобирает — отдельно звать `/index-sheets` не нужно.
- Критерий устаревания: файла нет · индексу > 14 дней · изменился список таблиц
  в `sheets-sources.txt` · изменился набор вкладок.
- Формат источника фиксирован: `…/edit?gid={GID}&range=A{N}:Z{N}`, где N — номер
  строки в таблице (шапка обычно строка 1, данные с 2).
