# wiki-search

Отвечает на вопрос сотрудника по внутренней вики. Не «где-то читал», а
**«вот в этом документе»** — с названием, разделом и полной ссылкой.

Идея: не тащить все 100 страниц. Есть карта `wiki-index.md` (по карточке на
документ). Читаем карту → выбираем 2-3 карточки, подходящие под вопрос →
открываем только эти страницы → отвечаем строго по ним.

Каталог проекта (там `wiki-index.md`, `fetch_pages.py`, `build_wiki_index.py`):
```
C:/Users/yliya/OneDrive/Документы/ailearning/wiki-search
```

## Что делать

1. **Прочитать карту.** Открыть `wiki-index.md` из каталога проекта (обычным
   чтением файла).
   - Файла нет → сказать пользователю: сначала запусти `/index-wiki`. Не
     продолжать.
   - В шапке дата `Собрано:` старше ~30 дней → предупредить, что карта могла
     устареть, и предложить `/index-wiki`; можно всё равно попробовать ответить.

2. **Выбрать 2-3 документа.** По полям `О чём` и `Вопросы` найти карточки,
   наиболее близкие к вопросу пользователя. Брать 2-3 штуки (одну — если
   совпадение очевидно и единственное). Если ни одна карточка даже близко не про
   это — сразу перейти к пункту 5 («в вики нет»).

3. **Открыть только выбранные страницы:**
   ```
   cd "C:/Users/yliya/OneDrive/Документы/ailearning/wiki-search"
   python fetch_pages.py <URL1> <URL2> [<URL3>]
   ```
   URL брать из строки `- URL:` соответствующих карточек. Скрипт печатает по
   каждой странице строку `Источник: <полный URL>`, шапку (заголовок, раздел,
   дата, автор) и чистый текст. Флаг `--json` — если удобнее машиночитаемо.

4. **Ответить строго по открытым страницам.** Обязательно:
   - только то, что реально есть в этих страницах;
   - **всегда указывать источник** — назвать документ и дать ссылку
     (`Источник: https://agentsim.online/wiki/…`); если ответ собран из
     нескольких документов — сослаться на каждый;
   - при противоречии документов (например «Тарифы (актуальные)» и «Прайс 2024»)
     — брать актуальный (свежая дата «Обновлено» / слова «актуальн»/«текущ» в
     названии) и это отметить;
   - если открытые страницы вопрос не покрывают — вернуться к пункту 2 и выбрать
     другие карточки (не больше 1-2 повторов), либо перейти к пункту 5.

5. **Если ответа в вики нет.** Прямо сказать, что в вики этого нет. Ничего не
   выдумывать и не додумывать.

6. **Никаких размытых формулировок.** Нельзя «кажется, где-то было», «обычно
   делают так». Только конкретный документ со ссылкой.

## Заметки

- Зависимостей нет — только стандартная библиотека Python 3.
- `fetch_pages.py` принимает только ссылки вида
  `https://agentsim.online/wiki/<раздел>/<слаг>`.
- Карту `wiki-index.md` строит и обновляет скилл `/index-wiki`
  (`python build_wiki_index.py`). Здесь её только читаем.
- Разделы вики: finance, general, hr, marketing, product, sales, tech.
