# company-search

AI-ассистент, который отвечает на вопросы по двум источникам компании DataPeople
— **корпоративной вики** и **таблицам менеджеров в Google Sheets** — всегда
**с указанием источника**.

Один приём для обоих источников: не читать всё подряд, а держать в корне репо
**один файл-индекс** (карточка на документ / на таблицу) и по нему выбирать
2-3 релевантных объекта, открывая только их.

```
/index-wiki    →  обходит всю вику, пишет wiki-index.md (карточка на документ)
/wiki-search   →  читает wiki-index.md → 2-3 страницы → ответ + ссылка на страницу

/index-sheets  →  обходит таблицы из sheets-sources.txt, пишет sheets-index.md
/sheets-search →  читает sheets-index.md → 2-3 таблицы → ответ + ссылка на строку
                  (?gid={GID}&range=A{N}:Z{N})
```

`/wiki-search` и `/sheets-search` перед поиском сами проверяют свежесть своего
индекса (`… check`) и при необходимости пересобирают его — отдельно звать
`/index-*` не нужно.

## Структура

| Путь | Что это |
|---|---|
| `wiki-index.md` / `sheets-index.md` | **общие артефакты данных** в корне: `/index-*` пишет, `/…-search` читает. Коммитятся. |
| `sheets-sources.txt` | список ссылок на таблицы менеджеров (вход для `/index-sheets`). |
| `wiki_common.py` / `sheets_common.py` | загрузка + парсинг источника. |
| `build_wiki_index.py` / `build_sheets_index.py` | сборка индекса + режим `check` (движки `/index-*`). |
| `fetch_pages.py` / `fetch_sheets.py` | открыть выбранные страницы / таблицы с источником (движки `/…-search`). |
| `.claude/skills/<name>/SKILL.md` | инструкции для Claude — **только инструкции, без данных**. |

Зависимостей нет — только стандартная библиотека Python 3.8+. Вика читается по
HTTP; таблицы — CSV-экспортом с доступом «по ссылке» (без OAuth).

## Быстрый старт

```bash
# вика
python build_wiki_index.py
python fetch_pages.py https://agentsim.online/wiki/sales/pricing-current

# таблицы
python build_sheets_index.py
python fetch_sheets.py 8                     # вся таблица №8 из sheets-sources.txt
python fetch_sheets.py 1 2 9 --filter Северсталь
```

## Форматы индексов

**`wiki-index.md`** — шапка (`Собрано:` · число документов · источник), дальше
карточки по разделам (finance, general, hr, marketing, product, sales, tech):

```
### <Заголовок документа>
- URL: https://agentsim.online/wiki/<раздел>/<слаг>
- Обновлено: 2026-01-15 · Автор: <имя>
- О чём: 2-3 предложения — про что документ.
- Вопросы: подзаголовок; подзаголовок; …
```

**`sheets-index.md`** — шапка (`Собрано:` · число таблиц), дальше карточка на
вкладку:

```
## Таблица 8 — Олег
- Таблица: https://docs.google.com/spreadsheets/d/<id>/edit
- Вкладка: oleg-clients-2025 · gid=1426144749 · строки данных 2–19
- Колонки: Компания | Контактное лицо | … | Этап воронки | …
- О чём: Менеджер — Олег … Личная таблица менеджера, строк данных: 18. Стадии …
- Компании/лиды: АгроТех Системы; МашСтройИнвест; РусХимГрупп; …
```

## Как понимается «индекс устарел» (`… check` → `OK` / `WARN` / `REBUILD`)

| Условие | Вердикт |
|---|---|
| файла-индекса нет / не читается шапка | `REBUILD` |
| индексу больше **14 дней** (по `Собрано:`) | `REBUILD` |
| вика: изменился список документов (дешёвая сверка 7 разделов) | `REBUILD` |
| таблицы: изменился список в `sheets-sources.txt` или набор вкладок | `REBUILD` |
| структуру не дала проверить сеть, но индекс не старше 14 дней | `WARN` (ищем по текущему) |
| иначе | `OK` |

На `REBUILD` `…-search` сам запускает полный `build_*_index.py` и только потом ищет.

## Выдача

Ответ только по реально открытым страницам / строкам, **всегда со ссылкой на
источник**: для вики — полный URL страницы; для таблиц —
`…/edit?gid={GID}&range=A{N}:Z{N}`. Если подходящей карточки в индексе нет —
«в источнике этого нет», без догадок.
