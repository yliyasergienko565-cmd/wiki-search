# wiki-search

Два скилла для ответов по корпоративной вики
[DataPeople](https://agentsim.online/wiki/) **с обязательным указанием
документа-источника**.

Идея — не читать все 100+ страниц на каждый вопрос:

```
/index-wiki   →  обходит всю вику, пишет один файл wiki-index.md
                 (карточка на документ: о чём + какие вопросы покрывает)

/wiki-search  →  читает wiki-index.md, выбирает 2-3 релевантные карточки
                 по описаниям, открывает только их страницы, отвечает
                 строго по ним и со ссылками
```

100 страниц → 1 файл индекса + 2-3 открытые страницы на запрос.

## Структура

| Путь | Что это |
|---|---|
| `wiki-index.md` | **общий артефакт данных** в корне репо: `/index-wiki` пишет, `/wiki-search` читает. Коммитится. |
| `wiki_common.py` | загрузка страниц вики (параллельно) + парсинг. Общий для обоих скиллов. |
| `build_wiki_index.py` | обход вики → сборка `wiki-index.md` (движок `/index-wiki`). |
| `fetch_pages.py` | открыть 2-3 конкретные страницы чистым текстом с `Источник:` (движок `/wiki-search`). |
| `.claude/skills/index-wiki/SKILL.md` | инструкция для Claude — только инструкция, без данных. |
| `.claude/skills/wiki-search/SKILL.md` | инструкция для Claude — только инструкция, без данных. |

Зависимостей нет — только стандартная библиотека Python 3.8+.

## Быстрый старт

```bash
python build_wiki_index.py                       # собрать/обновить wiki-index.md (~5-10 сек, 99 док.)

python fetch_pages.py \
  https://agentsim.online/wiki/sales/pricing-current \
  https://agentsim.online/wiki/finance/process-expense-approval
```

Как скиллы: `/index-wiki` — когда индекса нет или он устарел; `/wiki-search
<вопрос>` — на каждый вопрос по вике.

## Формат `wiki-index.md`

Шапка (`Собрано:` дата · число документов · источник), дальше карточки,
сгруппированные по разделам (finance, general, hr, marketing, product, sales,
tech):

```
### <Заголовок документа>
- URL: https://agentsim.online/wiki/<раздел>/<слаг>
- Обновлено: 2026-01-15 · Автор: <имя>
- О чём: 2-3 предложения — про что документ.
- Вопросы: подзаголовок; подзаголовок; …
```

## Как `/wiki-search` понимает, что индекс устарел

Читает шапку `wiki-index.md`: файла нет → просит запустить `/index-wiki`; дата
`Собрано:` старше ~30 дней → предупреждает и предлагает пересобрать. Пересборка —
всегда полный проход `build_wiki_index.py` (быстрый, параллельный).

## Выдача

Ответ только по 2-3 реально открытым страницам, **всегда с полным URL
источника**. Противоречия между документами разрешаются в пользу актуального
(свежая дата «Обновлено» / «актуальн»/«текущ» в названии). Если ни одна карточка
индекса не подходит — «в вики этого нет», без догадок.
